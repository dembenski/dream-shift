# DREAM SHIFT

A tiny dream you can walk in. A trippy first-person dream-simulator walking game for GitHub Game Off 2026 (theme: SHIFT).

Press SHIFT and the dream redesigns itself — new zone, new textures, new camera, new controls, new spawns. Walk through portal rings for a free SHIFT. Fill the Shift Meter for a MEGA SHIFT. No way to lose. Bump things — they giggle.

**v3.1 — 8 new SHIFT effects:** SNACK RAIN (snacks rain from the sky), SLOW DREAM (dreamy slow-mo), GIGGLE DREAM (everyone laughs, gentle wobble), CANDY DESERT (candy desert — find the giant juice box!), DREAM THOUGHTS (philosophical NPCs), DONUT PORTAL (giant donut portal = free MEGA SHIFT), DREAM DRIFT (slow move, world drifts to you), THE TREES ARE AWAKE (cute googly eyes on the trees).

**v3.2 — renamed to DREAM SHIFT + 9 electronic-music-video visual effects:** KALEIDOSCOPE (mirror-flower symmetry), NEON PULSE (the world breathes with the beat), RAINBOW DRIFT (slow hue cycle), VORTEX (gentle spiral + sparkles), MIRROR DREAM (the world flips sideways), LASER DREAM (slow sweeping light beams), FRACTAL BLOOM (jewel mandalas bloom in the sky), BREATHING WORLD (trees and ground gently swell and flow), TUNNEL OF LIGHT (slow FOV pull through glowing rings). All visuals are slow and gentle — no strobing, no flashing.

**Controls:** WASD / arrows to walk, mouse look (click to lock), SHIFT to shift, Space to bonk, P to pause. Touch: drag to look, hold-to-walk button, on-screen SHIFT button.

Built by Michael Dembenski & Bit. AI-assisted: code built with Muse (Bit); textures generated with AI image generation. Three.js r160 vendored locally, no CDN.

**Play locally:** serve over HTTP (`python3 -m http.server`) — ES modules don't work from `file://`.
