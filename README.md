# SHIFT TRIP

A tiny dream you can walk in. A trippy first-person dream-simulator walking game for GitHub Game Off 2026 (theme: SHIFT).

Press SHIFT and the dream redesigns itself — new zone, new textures, new camera, new controls, new spawns. Walk through portal rings for a free SHIFT. Fill the Shift Meter for a MEGA SHIFT. No way to lose. Bump things — they giggle.

**Controls:** WASD / arrows to walk, mouse look (click to lock), SHIFT to shift, Space to bonk, P to pause. Touch: drag to look, hold-to-walk button, on-screen SHIFT button.

Built by Michael Dembenski & Bit. AI-assisted: code built with Muse (Bit); textures generated with AI image generation. Three.js r160 vendored locally, no CDN.

**Play locally:** serve over HTTP (`python3 -m http.server`) — ES modules don't work from `file://`.
